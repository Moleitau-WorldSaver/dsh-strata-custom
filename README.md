# 历史提问地图 · dsh-strata 定制版

**在长对话里，找回你问过的每一句话。**

> 不用再往上翻。鼠标停在屏幕右边缘，弹出这个会话里**你问过的每一条提问**；点一下，直接跳回那一轮。

## 你是不是也这样

聊到第 80 轮，忽然想起来：「我前面好像问过一个类似的。」

于是开始往上滚。滚轮搓得冒烟，屏幕刷过一片残影——**滚了十几秒，没找到**；再往回滚一点，又滚过了。

打开 `Ctrl+F`？可你记不住当时的原话。

**在长会话里，「我问过什么」比「助手说过什么」更难找。**

这个插件专门解决这一件事。

---

## 它做什么

把**整段会话**压成贴着右边缘的一幅**地图**，再把**你的每一条提问**摊成一面**卡片墙**。

### 🔍 历史提问面板 —— 一份会话的目录

鼠标移到右边缘的蓝色按钮上，弹出本会话**每一条提问**的卡片列表，从上到下就是时间顺序。

它**不是搜索框，是目录**。所以你没有必要记得原话——只要认得出「哦，是那次问的」，扫一眼就能定位。

### 🖱 点一下，就回去

点任意一张卡片，对话区直接滚到那一轮。不用搓滚轮，不用估算位置，一次到位。

### 👤 你自己说的话，最显眼

地图上，**你的提问**用亮色高亮，助手的回复压暗。

所以「我问过什么」这件事，扫一眼地图就看出来了——而不是在一大片同质的文字里一点点扒。

### 📐 地图是**等比**的，不是刻度尺

每一条消息按它**真实的渲染高度**占据地图上的一段。长回复占得宽，短问题占得窄。

于是**地图的形状 = 这段会话的形状**：哪几轮聊得深、哪里只是一句话带过，一眼有数。

原生滚动条只告诉你「你在哪」，不告诉你「这里是什么」——这张地图两样都告诉你。

### 🎡 滚一格，翻一条

滚轮**逐条步进**：一格 = 一条消息。不会一滑滑过头，也不会卡在两张卡片中间。

### ⏳ 往回翻，历史自动长出来

往上步进时，更早的历史会**自动加载**进来，地图跟着一起长。不用手动点「加载更多」。

### 🔒 零数据通道

**不联网、不读会话状态、不发任何请求。**

几何和语义全部来自对话视图**本来就渲染在 DOM 上**的锚点属性。你的对话内容不经过它，它也不存任何东西。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 鼠标移到右边缘蓝点 | 展开「历史提问」卡片墙 |
| **滚轮** | 一格 = 一条消息，逐条步进 |
| **点卡片** | 跳回那一轮，卡片亮起蓝色焦点框 |
| 滚到列表尽头 | 弹一句提示（"你底到我啦" / "你顶到我啦"）；**不吞滚轮事件**，页面照常滚 |
| **拖动蓝点** | 按钮拖到顺手的位置，位置记在 `localStorage`，刷新后保留 |
| 窄屏 / 移动端 | 卡片自动单列 |

---

## 为什么不是 Ctrl+F

`Ctrl+F` 搜的是**文本**——前提是你记得原话。

这张地图组织的是**轮次**——你只需要认得出「是那次问的」。

而且 `Ctrl+F` 一次只定位一处。「我问过什么」这种**扫描式**的需求，它帮不上忙。

## 安装

这是一个 DSH **profile 插件包**（`dsh.bundle` + `dsh.client` 双声明）。

```bash
dsh plugin --profile web add github:Moleitau-WorldSaver/dsh-strata-custom
```

装完刷新 DSH Web GUI 即可看到。

> 想改源码：`git clone` 这个仓库，改 `client.js` 后刷新页面就生效——没有构建步骤。
> 要在别的 profile 里用本地目录装载，把 clone 下来的目录路径当包路径装进去即可。

### ⚠️ 两个注意

- **包名仍是 `dsh-strata`**，所以**不能和上游原版同时安装** —— 两者会争抢同一个 `cordis.patch.yml` 里的 `id: strata` 装配位。装之前请先卸掉另一个。
- **没有构建步骤**：`client.js` 就是手写源码，由 DSH 的 client-modules 直接下发给浏览器。**改完刷新页面即刻生效**，不需要 `npm run build`。

---

## 给想二次开发的人

- **没有构建步骤。** `client.js` 就是手写源码（factory 格式）。改一行、刷新页面、立刻看到效果 —— 没有打包、没有 bundle 缓存。
- **没有后端。** Node 半边（`index.js`）是**故意留空**的：无 host state、无工具、无 remote、无会话数据过网。它存在只是为了让 composition row 能解析到这个包。
- **改 UI 只要认两处**：顶部的 CSS 块（`.dsh-strata-*`）和 `mountMinimap()`。
- **卸载是干净的**：disposer 会清掉自己新增的全部节点与监听。
